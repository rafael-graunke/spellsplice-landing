Spellsplice is an unofficial, open-source Magic: The Gathering overlay
editor. It runs entirely in your browser. There are two ways to use it:

- **Timeline** — import match footage, arrange clips on a non-linear timeline,
  and build a synchronized track of in-game events (life changes, draws,
  reveals, stack interactions) that get baked into an exported video.
- **Live Mode** — drive an overlay in real time from a controller
  window, added to OBS as a transparent **Browser Source**. No chroma key or
  manual cropping needed.


## Where to start

- New here? Read [Getting Started](/docs/getting-started).
- Setting up your overlay's look? See
  [Overlay Configuration](/docs/overlay).
- Streaming live? See [Live Mode](/docs/live) and
  [Broadcasting to OBS](/docs/live/broadcasting-obs).
- Want your own scoreboard graphic? See
  [Custom Scoreboard SVG](/docs/overlay/scoreboard-svg).

## Open the app

The editor lives at [app.spellsplice.com](https://app.spellsplice.com). It needs
a Chromium-based browser (Chrome or Edge) for video export, which uses
WebCodecs.
