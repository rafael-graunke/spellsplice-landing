## Reset Match

![The reset confirmation dialog](/docs-assets/live/match-controls-reset.png)

**Reset Match** asks for confirmation, then:

**Cleared**

- both hands
- all annotations on both sides
- life totals, back to 20

**Kept**

- wins
- decklists
- player names

That split is deliberate: it is the "next game of the same match" button. Bump
the winner's [wins](/docs/live/player-panel#wins) first, then reset, and the
scoreboard carries the match score into game two.
